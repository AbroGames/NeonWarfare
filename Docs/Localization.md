# Локализация

[← README проекта](../README.md)

Файлы перевода — `Assets/Locales/en.po` и `ru.po`, шаблон — `messages.pot`.
Текущая локаль выставляется в `RootStarter` **после** загрузки настроек, но **до** первого показа
экрана загрузки. Локаль по умолчанию берётся из ОС (`Services.I18N.GetUserOsLocaleInfoOrDefault()`).  
Сменить язык в игре можно на странице `LanguageSelectionPage`.
  
Разработчик может выбрать языки, на которых будут отображаться сцены проекта в редакторе (на игру это не влияет).
Для этого над сценой, в выпадающем меню выбрать "Вид -> Предпросмотр перевода".
При отсутствии выбора языка (пункт "нет") будут показываться ключи локализации.
