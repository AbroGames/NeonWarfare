# Режимы запуска игровой сессии

[← README проекта](../../README.md)

| Стартер | Сеть | Кто хост | Когда используется |
|---|---|---|---|
| `SingleplayerGameStarter` | нет (`Network` не создаётся) | процесс сам себе сервер | Одиночная игра из меню, `--auto-start` (+ `--auto-start-savefile`) |
| `HostMultiplayerGameStarter` | ENet-сервер | этот же процесс | Хост «изнутри клиента» и выделенный сервер |
| `ConnectToMultiplayerGameStarter` | ENet-клиент | удалённый процесс | Подключение к серверу, `--auto-connect` |
| `HostDedicatedServerAndConnectGameStarter` | ENet-клиент + дочерний процесс | отдельный процесс-сервер | Хост с вынесенным сервером: поднимает второй процесс с `--server` и подключается к нему |

В одиночной игре и в главном меню `Net.IsServer()` возвращает `true` — процесс сам себе авторитет.
`false` он возвращает **только** тогда, когда мы подключены как клиент к чужому серверу.
Это позволяет писать серверную логику один раз и не дублировать её для одиночного режима.
